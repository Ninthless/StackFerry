### 中文

### 更新范围

本版本聚焦 StackFerry 独立仓库的发布体验，整理多平台构建、自动更新和版本说明的协作流程。

### 发布说明与维护体验

- 发布正文采用中英双语并按功能领域组织，用户可以先阅读面向体验的变化，再查看完整提交记录。
- 版本发布后自动补充本版本提交和贡献者信息，减少手工整理发布说明的工作量。
- 构建产物、更新清单和签名文件继续由同一条多平台工作流生成，保持安装与应用内更新的一致性。

### English

### Scope

This release focuses on the independent StackFerry release experience, including the multi-platform build, automatic update, and release-note workflow.

### Release Notes And Maintenance

- Release notes now use a bilingual, feature-oriented structure so user-facing changes come before the full history.
- Each release automatically includes the commits and contributors for that release, reducing manual release-maintenance work.
- Build artifacts, update manifests, and signatures continue to be produced by the same multi-platform workflow for consistent installation and in-app updates.
